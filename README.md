## Project Background

Chicago 311 service requests (2011 onward) and community-area demographics, read
from Box at `dsi-core/clinic/2026-sample/raw/`.

## Project Goals

Summarize 311 request volume and response times by community area and service
type, and show them on the dashboard.

## Data

Set `DATA_DIR` in `.env` (copy `.env.example`) to the Box folder, then run
`make check-data` to confirm you can read it and that Box is syncing.

### Docker & Make

We use `docker` and `make` to run our code. There are three built-in `make` commands:

* `make build-only`: This will build the image only. It is useful for testing and making changes to the Dockerfile.
* `make run-notebooks`: This will run a jupyter server which also mounts the current directory into `\program`.
* `make run-interactive`: This will create a container (with the current directory mounted as `\program`) and loads an interactive session. 

The file `Makefile` contains information about about the specific commands that are run using when calling each `make` statement.





### Dashboard

The project includes an optional browser dashboard built with Vite, React, and
DuckDB-wasm.  It queries parquet files in the browser — no backend required.

**Start it locally (pull the example data from Box first):**

```bash
make dashboard-data
make dashboard-dev
```

Open http://localhost:5173.

**Build for deployment:**

```bash
make dashboard-build
```

See `TUTORIAL.md` for a step-by-step walkthrough, `dashboard/README.md` for
the command reference, and `PROJECT_SETUP.md` for one-time mentor setup
(Cloudflare Pages deployment, Box static links).
